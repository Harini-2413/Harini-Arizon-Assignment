# Arizon E-Commerce Frontend

This is a simple e-commerce frontend built using *React, **Tailwind CSS, and **Context API* for state management. It includes a product listing page, a mini cart, and navigation.

## Features

- Home page
- Product listing page
- Add to cart functionality
- Mini cart display with subtotal
- Navigation header (Home, Products, Cart)
- Responsive design with Tailwind CSS

## Technologies Used

- React.js
- React Router DOM
- Tailwind CSS
- Context API
